### Quick Launch Commands:
1. **Backend:**
   ```powershell
   python -m uvicorn barrierguard.backend.app.main:app --port 8000 --reload
   ```
2. **Web Dashboard:**
   ```powershell
   cd barrierguard\web; npm run dev
   ```
3. **Mobile App:**
   ```powershell
   cd barrierguard\mobile; npx expo start --web
   ```
